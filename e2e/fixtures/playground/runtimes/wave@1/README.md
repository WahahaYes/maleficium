# wave@1

A pixel-art robot that waves and watches the mouse, adapted from the author's own waving-robot page on his website (its built page, copied; the website copy is unchanged). The backdrop and the speech bubble take the paper's figure tokens, so the widget matches the page in light and dark mode.

```latex
\interactiveruntime[runtime=wave@1, alt={A pixel-art robot waving},
  id=fig-wave]{words/greeting.txt}
```
