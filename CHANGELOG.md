# Changelog

## 0.1.0

First public release for Linux x86_64.

- Desktop-native LaTeX editor (Tauri 2 + Rust, React + MUI).
- Bundled Tectonic engine; fully offline after the first bundle download.
- Bundled SyncTeX command-line tool for forward and inverse search.
- Installable as `.deb` and AppImage; build from source per `BUILDING.md`.
