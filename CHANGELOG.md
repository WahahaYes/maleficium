# Changelog

## 0.1.0

First public release, for Linux x86_64 (`.deb` and AppImage).

- Editor and side-by-side PDF preview with SyncTeX in both directions.
- Bundled Tectonic engine: no TeX install needed, and fully offline after the first compile downloads its support files.
- Pre-compile check for missing packages, fonts, and tools.
- Project search and replace with preview and one-step undo.
- Document outline, go to definition, file finder, and command palette.
- Revision history for every saved file, kept outside the project.
- Nine built-in starter templates (CC0), plus saving your own.
- Bundled VS Code color themes, dark and light.
