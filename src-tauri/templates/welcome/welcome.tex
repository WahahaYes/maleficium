\maketitle

This is a real project: edit it, break it, compile it. It lives in the
app's own data folder, so nothing you do here touches your files.

\section{Compile}
Press \textbf{Ctrl+R} to compile. The first compile downloads the \TeX\
support files it needs (a minute or so) and says so in the status bar;
after that, compiles run from the local cache in about a second, with or
without a network. With \textbf{Tools $\rightarrow$ Auto-Compile on Save}
on, every save recompiles.

\section{Work offline}
The badge in the status bar says whether a project compiles offline.
\textbf{Tools $\rightarrow$ Make Available Offline} fetches everything a
document needs while you still have a connection.

\section{Jump between source and PDF}
Click the PDF to jump to the line that made it, or press
\textbf{Ctrl+Alt+J} in the editor to find the current line in the PDF.
Zoom with \textbf{Ctrl+=} and \textbf{Ctrl+-}; \textbf{Ctrl+0} fits the
page width.

\section{Find things}
\textbf{Ctrl+F} finds in the file, \textbf{Ctrl+Shift+F} across the
project, and the command palette lists everything the app can do.

\section{Start something real}
\textbf{File $\rightarrow$ New Project from Template} offers articles,
reports, books, letters, slides, assignments, a CV, a resume and a journal
paper, each ready to compile. \textbf{File $\rightarrow$ Save Project as
Template} turns any project into one of your own.

\section{Your work is kept}
Every save records a revision you can return to (\textbf{Ctrl+H}), and
deleted files go to a trash you can undo from. \textbf{File $\rightarrow$
Export} writes the PDF, or the whole project as a zip, wherever you like.
